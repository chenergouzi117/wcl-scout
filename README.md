# WCL Scout

魔兽世界插件与本地助手：在游戏中选择队友或集合石申请者，按需查询其公开 WCL 大秘境或团本记录。支持单查、一键全查和深度分析；不会自动查询所有申请者。

**第一次使用？请按图文版[中文安装指南](docs/安装指南.md)操作。**

## 安装与启动（Windows）

1. 安装 Node.js 20 或更高版本。
2. 将 `addon/WCLScout` 文件夹复制到 `World of Warcraft/_retail_/Interface/AddOns/`。安装后应存在 `.../AddOns/WCLScout/WCLScout.toc`。
3. 双击 `start-wcl-scout.cmd`，保持窗口打开。本地页面为 <http://127.0.0.1:17385>。
4. 首次使用时在本地页面填写自己的 WCL V2 Client ID 和 Client Secret。凭据只保存在本机 `%APPDATA%/WCLScout/config.json`，不要上传或分享。
5. 在游戏中输入 `/wcls` 打开界面。点击查询后，先 `/reload` 提交；等待本地助手处理，再 `/reload` 载入结果。

游戏插件不能直接访问互联网；新查询、一键全查和深度分析需要本地助手运行。已经写入 `Data.lua` 的缓存可以离线查看，但不会自动更新。默认筛选 15 层及以上；本人“成长分析”可查看 5 层及以上。

## 评分边界

大秘总分、最高层、限时率和词缀不参与技术评分。同层输出分会受路线、合波、装备和队友影响。部分专精没有通过跨副本验证，综合技术分会显示“待验证”，不应将其理解为零分或限时成功概率。

## 数据与隐私

仓库和发行包不包含开发者的 WCL 密钥、个人查询缓存、战斗日志或原始采样报告。`addon/WCLScout/Data.lua` 是空白初始文件；本地助手运行后会在用户电脑上生成缓存数据。`data/band-standards` 提供聚合对比标准。

源码无需额外 npm 依赖。运行测试：`npm test`。
